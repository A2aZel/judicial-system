# ADR 0003: Ориентир по основному наказанию

Рекомендация строится по обстоятельствам дела. Отдельное поле для проекта наказания в интерфейсе не требуется. API сохраняет возможность формальной проверки черновика для прежних клиентов.

В расчёт входят сопоставимые дела той же части ст. 290 с одинаковыми процессуальными условиями. Одно дело учитывается один раз. При заданной сумме дополнительно отбираются дела с надёжно извлечённой суммой взятки от одной трети до трёх введённых сумм. Это рабочий порог сопоставимости для прототипа.

Каждое выбранное смягчающее или отягчающее обстоятельство должно быть подтверждено в деле-аналоге. Для нескольких отметок требуется их совместное наличие. Отметки с неизвестным статусом остаются за пределами такого отбора. Дела берутся из проверенной разметки или из текста, где суд прямо признал обстоятельство. Приложение показывает выбранные признаки и размер оставшейся выборки. Когда пользователь оставляет поля обстоятельств пустыми, расчёт использует остальные заданные условия.

Учитываются однозначно определённые основные наказания. Для каждого вида с достаточной поддержкой показываются медиана и интервал между первым и третьим квартилями. При равной поддержке выводятся оба варианта, при недостатке наблюдений отображается причина.

Текущий текстовый индекс и числовые признаки старой выгрузки строились по полным приговорам, поэтому могут содержать сведения о наказании. Они используются для просмотра похожих дел. Сумма для расчёта берётся из проверенных полей или однозначной формулировки о размере самой взятки в фактической части приговора. Для включения текста в ранжирование рекомендации нужен отдельный индекс по сведениям, доступным до решения, и проверка качества поиска.

Исторический интервал описывает выборку. Правовые санкции зависят от применимой редакции УК, индивидуальных обстоятельств и правил назначения основных и дополнительных наказаний. Пока автоматическая проверка этих ограничений имеет статус `not_checked`. Обоснование строится из проверяемых счётчиков и правил расчёта. Генеративная модель не требуется.
