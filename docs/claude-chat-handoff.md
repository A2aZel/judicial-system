## 2. Критика (ответ Claude, 25.10)

Архитектура:
- модели выбраны раньше, чем проверены данные;
- на обучении модель видит текст приговора, а на применении — другие документы;
- цель прогноза не определена: наказание состоит из нескольких частей (основное,
  дополнительное, кратный штраф, ст. 73, конфискация, совокупность по ст. 69);
- особый порядок и досудебное соглашение (ст. 62) смешивают несравнимые дела;
- гибрид не определён: две оценки на одном корпусе не независимы;
- одна рекомендованная цифра работает как якорь, а приговоры с подсказкой, попав в
  обучение, усиливают смещение;
- тайна совещания (ст. 298 УПК), запрет ссылаться на статистику в мотивировке (ст. 307 УПК);
- правовой модуль недооценён; китайская модель опирается на формализованные указания,
  которых в РФ нет.

Пленум:
- изучали квалификацию (№ 24), а система — про наказание: нужны № 58, № 60 (2006, особый
  порядок), № 16 (2012, досудебное соглашение), № 17 (2018, конфискация);
- ответ «почему так трактует» был формальным: мотивировки в постановлениях нет, её
  восстанавливают по обзорам, материалам заседаний, НКС, КС, комментариям;
- неясно, куда позиции Пленума встраиваются в систему; тема резонанса уводит в сторону.

Модели:
- модели подобраны по описаниям на Hugging Face, а не по русским бенчмаркам (сравнить
  FRIDA, USER-bge-m3);
- возможное требование российского ПО;
- нужен ли LLM вообще;
- длина документов больше окна моделей.

## 3. Решения пользователя (25.10)

1. Анализ данных нужен.
2. Вопрос: нужны ли оригинальные материалы дела?
3. Наказание нужно считать целиком.
4. Согласен с процессуальными режимами как фильтрами.
5. Не уверен, что будет размеченный вручную корпус, — сколько нужно?
6. **Цель решения — уменьшить количество апелляций.**
7–8. Ограничения понятны.

Модели:
- Qwen приводит результат в читаемую форму и называет причины и значимость условий;
- длинные документы — записать в архитектуру.

Ответы Claude:
- **Оригиналы.** Для обучения не нужны: вход — карточка с фактами, установленными судом.
  Обвинительные заключения нужны только для проверки предзаполнения, через пилотный суд.
- **Разметка (оценки).** Карточки для NER — 300–500 + 100–150 для теста; апелляционные
  акты — 500–1000, около 10 категорий причин; пары «похожи / не похожи» на старте не нужны.
- **Цель.** Метрика — доля приговоров, изменённых в апелляции из-за наказания
  (п. 3–4 ст. 389.15 УПК), а не число жалоб. Правовой модуль — ключевой; kNN показывает
  наказания после апелляции; BERT оценивает риск апелляции для проекта наказания.
- **Значимость условий.** Её считает отдельный модуль по аналогам, Qwen только излагает.

## 5. Прерванная задача: официальные сайты судов как источник апелляций

**Зачем.** Модели риска апелляции нужны пары «приговор → апелляционное решение». В СудАкт
их почти нет. Нужно понять, дают ли их официальные сайты судов.

**Что проверить по каждому суду:**

| Критерий | Вопрос |
|---|---|
| Доступность | Открывается ли сайт отсюда; есть ли защита от ботов или капча |
| Поиск | Можно ли искать уголовные апелляционные дела по ст. 290 и за период |
| Объём | Сколько таких дел за год |
| Связка | Видны ли в карточке суд, номер, дата первой инстанции и УИД |
| Тексты | Опубликован ли текст апелляционного решения; есть ли в нём причины изменения |

**Сделано до остановки (08.11.2026):**

- **Мосгорсуд** (`mos-gorsud.ru`, отдельный портал):
  - Поиск доступен, в форме есть поля `codex` (статья), `instance`, `uid`, `caseNumber`,
    даты, `publishingState`, `baseDecision`. На странице капча Яндекса
    (SmartCaptcha, поле `smart-token`).
  - Запрос
    `https://mos-gorsud.ru/mgs/search?formType=fullForm&caseType=CRIMINAL&instance=2&codex=ст.+290&caseDateFrom=01.01.2025&caseDateTo=31.12.2025`
    вернул **«найдено записей: 687»** — апелляционные уголовные дела Мосгорсуда со ст. 290
    за 2025 год. Капчу решать не пришлось.
  - В таблице результатов есть колонки «Решение первой инстанции» и «Решение апелляционной
    инстанции». В колонке «Стороны» указаны статья и часть по каждому обвиняемому.
  - В результатах фамилии не обезличены.
  - Не проверено: карточка дела (например, `10-27048/2025`) — указаны ли первая инстанция
    и УИД, опубликован ли текст решения; проходит ли листание страниц и открытие карточек
    без капчи; сколько из 687 дел — апелляции на приговор, а не материалы о мере пресечения.

**Осталось:**

1. Мосгорсуд: открыть 3–5 карточек из выдачи и проверить критерии из таблицы.
2. Проверить 3–4 областных суда на sudrf.ru. Кандидаты — суды регионов, чьи приговоры
   попали в выборку: Саратовский, Воронежский, Свердловский областные, Красноярский краевой.
   Адреса сайтов взять из справочника судов на sudrf.ru, раздел «Судебное делопроизводство» —
   уголовные дела апелляционной инстанции. Портал `bsr.sudrf.ru` отсюда не открывался.
3. Записать результат в `corpus/court_sites_check.md`: таблица по судам с критериями,
   датой проверки и ссылками.
4. Обновить в `judicial-ai-architecture.html` раздел «Данные» (таблица и «Вывод для плана»)
   и `corpus/README.md`.

**Правила.** Капчу не обходить: если появилась — остановиться и отметить. Запросы — по
одному, с паузами. Персональные данные из карточек в документы не переносить.
