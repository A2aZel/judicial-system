# Интерактивный браузер для судов

**Уточнение от 09.11.2026:** для трёх судов `krk`, `vrn`, `svd` пользователь отдельно разрешил обычный сбор открытых текстов вопреки прежнему локальному ограничению по `robots.txt`, с паузами не менее 4 секунд. CAPTCHA и отказ в доступе остаются условиями немедленной остановки; их решение или обход агентом не разрешены. См. [collection-2026-11-09.md](collection-2026-11-09.md). Ниже сохранён прежний ручной сценарий и его исторические ограничения.

Запуск из корня проекта:

```bash
# Красноярский, Воронежский и Свердловский суды
python tools/court_browser.py krk vrn svd

# Саратовский суд
python tools/court_browser.py sar
```

Скрипт открывает только главные страницы официальных судов в видимом Chrome с постоянным профилем
`work/court-browser-profile`. Сессия и пройденные пользователем проверки сохраняются между запусками.

## Границы

- Поиск, листание, скачивание и обход CAPTCHA автоматически не выполняются.
- Пользователь сам проходит CAPTCHA, выполняет поиск и экспортирует документы.
- Красноярский и Воронежский сайты запрещают `/*name=sud_delo` в `robots.txt`. Там допустима только
  ручная работа пользователя, а не автоматический скрапинг.
- Номера дел, УИД, ФИО и содержимое карточек не выводятся в консоль или публичные отчёты.
- Скачанные вручную документы хранятся локально в `corpus/regional/raw/import/` и не публикуются.

После ручного экспорта можно продолжить обработку локальных документов через существующий pipeline,
сохраняя статусы `robots_blocked` для автоматического сбора.
