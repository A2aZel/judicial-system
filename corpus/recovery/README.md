# Ревизия отклонённых кандидатов Москвы

Цель — проверить до 50 ранее отклонённых кандидатов без изменения существующего processed dataset и dense index.

## Отбор

Статусы `verification_failed`, `no_compatible_attachment`, `download_error`, `manual_review` из `corpus/mosgorsud/raw` и `corpus/expansion/raw`.

Порядок приоритета:

1. Потерянные алиасы.
2. Не тот attachment или тип документа.
3. Формат номера/даты.
4. Частично скачанные документы и ошибки доступа.
5. Остальные.

Внутри приоритета — год и исходный ID, без выбора только удобных исходов. Отбор не изменяет распределение исходов.

## Команды

```bash
# Показать приоритеты без скачивания.
python tools/recover_pairs.py select

# Полная ревизия до 50 кандидатов с checkpoint.
python tools/recover_pairs.py recover --pause 4

# Агрегированный отчёт.
python tools/recover_pairs.py report
```

Запросы только последовательные с паузой 4 секунды. Никаких `/search` и robots-blocked путей. CAPTCHA не решается и не обходится. HTTP 404 сохраняет ошибку документа и не останавливает ревизию; CAPTCHA останавливает сразу.

## Строгая проверка

- Сначала перебираются совместимые attachments, затем резервная связка UID+court+number по официальному набору первой инстанции.
- Алиасы используются только при подтверждённых совпадающих дате и типе.
- Резервная первая инстанция должна быть единственной совпадающей записью с документом приговора и датой не позже апелляции.
- Полная пара требует два полных текста, SHA256 и текущий `verify_pair`: тип, суд, даты, номер и идентичность апелляции. Цитата приговора в апелляции не считается.
- Новый приговор нового рассмотрения не подставляется вместо обжалованного.
- Outcome вычисляется из проверенного текста и не отделяет `unknown` от negative.

`raw/` содержит документы, URL, идентификаторы и checkpoint и не предназначен для commit/public. `report.md` содержит только агрегаты по статусам, причинам, исходам и годам.

## Тесты

```bash
python -m pytest tests/test_recover_pairs.py -q
```

Синтетические тесты используют вымышленные документы и fake transport; PII не используется.
