# Расширение полных пар вне 2022–2025

Цель — увеличить число подтверждённых полных пар, не изменяя существующие 50 и dense index до отдельной проверки.

## Источники

- Апелляции Москвы: https://data.mos-gorsud.ru/opendata/1577117758402-casesgroupmgsappealcriminalquiik
- Первая инстанция Москвы: https://data.mos-gorsud.ru/opendata/1577116724824-casesgroupfirstcriminalluivn
- Условия: https://data.mos-gorsud.ru/terms-of-use

Используются только уже скачанные официальные наборы и прямые ссылки на документы из них. 207 ранее обработанных кандидатов не повторяются.

## Команды

```bash
# Отобрать кандидатов вне 2022–2025 без новых сетевых запросов.
python tools/expand_pairs.py select

# Возобновляемое скачивание с checkpoint.
python tools/expand_pairs.py download --pause 4

# Ограниченный блок.
python tools/expand_pairs.py download --limit 10 --pause 4

# Агрегированный отчёт без реквизитов дел.
python tools/expand_pairs.py report
```

`raw/pair-progress.json` хранит URL, SHA и статусы. `raw/texts/` содержит документы и не предназначен для commit/public. `report.md` содержит только агрегаты.

## Identity и ошибки

- Полная пара засчитывается после получения обоих полных текстов, проверки SHA256 и текущего московского `verify_pair`.
- Ошибки identity не скрываются: `verification_failed`, `manual_review`, `no_compatible_attachment`, `unsupported_format`, `download_error`, `captcha`.
- HTTP 404 сохраняется на кандидате, и сбор продолжается. CAPTCHA останавливает сразу; серия трёх не-404 ошибок подряд останавливает после checkpoint.
- Сохранённые ошибки не повторяются без `--retry-errors`.

## Другие регионы

Проверенные ранее региональные картотеки ГАС «Правосудие» закрыты `/*name=sud_delo` в robots.txt, поэтому не используются. Верховный Суд РФ публикует судебные акты, но не готовые пары «приговор → апелляция». Сторонние парсеры, непроверенные Hugging Face datasets и источники без понятной лицензии не используются.

На текущем этапе подходящий официальный загружаемый источник полных пар по другим регионам не найден. Это не вывод об отсутствии таких источников вообще: для следующего увеличения нужен официальный экспорт с обоими текстами и разрешённой связкой первой инстанции.
